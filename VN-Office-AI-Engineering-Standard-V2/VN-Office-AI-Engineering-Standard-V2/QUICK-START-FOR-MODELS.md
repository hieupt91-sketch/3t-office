# Quick Start for Coding Models
Before doing anything:
1. Read `AGENTS.md`.
2. Read Non-Negotiable Rules.
3. Read Architecture.
4. Identify your owner area.
5. Search source for existing LibreOffice capability.
6. Do not code until layer/reuse decision is clear.
7. If non-trivial, write plan.
8. Work only in assigned branch/worktree.
9. Build/test honestly.
10. Finish with Agent Handoff.

Golden rule:
**VN Office should look and feel like its own product while inheriting as much proven LibreOffice engine behavior as possible.**
