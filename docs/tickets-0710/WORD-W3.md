# WORD-W3: So sánh/Gộp tài liệu, Hạn chế chỉnh sửa, Bảo vệ bằng mật khẩu
Bằng chứng: không thấy Compare, Combine, Restrict Editing, Protect Document (mật khẩu) trong VN Doc.
Làm: Xem lại ▸ So sánh: tạo tài liệu mới với các thay đổi đánh dấu (chèn/xóa) theo đoạn; Hạn chế chỉnh sửa: chỉ cho phép theo dõi thay đổi hoặc chỉ đọc, đặt mật khẩu bỏ bảo vệ; (mã hóa tệp bằng mật khẩu mở file cần quyết định riêng của chủ sở hữu vì thuộc ranh giới bảo mật).
Nghiệm thu: Word thật mở DOCX, đọc ProtectionType/Revisions đúng; test CDP; hướng dẫn tiếng Việt.
