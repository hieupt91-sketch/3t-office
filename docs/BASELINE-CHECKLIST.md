# Danh mục cơ bản bắt buộc — VN Writer / VN Sheet / VN Slides

Ngày lập: 30/09/2026 · Yêu cầu người phụ trách: "rà soát kỹ các phần cơ bản của một ứng dụng Word, Sheet, Slide phải có", lỗi chi tiết làm dần.
Mỗi mục là ĐẠT khi: làm được bằng chuột VÀ phím tắt như Office, kết quả giống Office, lưu ra mở lại bằng Office thấy đúng, có hoàn tác (Ctrl+Z).
Cột "Gói" = gói việc trong docs/ROADMAP-V1.md chịu trách nhiệm.

## A. Chung cho cả 3 ứng dụng (Gói G7 + G4)
| # | Mục | Chuẩn Office |
|---|---|---|
| A1 | Khởi động | Tài liệu trống (không dữ liệu mẫu), tiêu đề Tài liệu1 / Bảng tính1 / Bản trình bày1 |
| A2 | Mới | Ctrl+N, tài liệu trống mới, đánh số tiếp |
| A3 | Mở | Ctrl+O, lọc đúng định dạng, báo lỗi rõ ràng khi hỏng, giữ tài liệu đang mở |
| A4 | Lưu | Ctrl+S; tài liệu mới → Lưu thành; tài liệu đã mở → lưu đúng định dạng gốc |
| A5 | Lưu thành | F12, chọn định dạng (docx/doc/pdf, xlsx/xls/csv/pdf, pptx/ppt/pdf), hỏi ghi đè |
| A6 | Đóng khi chưa lưu | Hỏi Lưu / Không lưu / Hủy |
| A7 | In | Ctrl+P, xem trước đúng trang, chọn máy in, số bản, phạm vi trang; in ra PDF đúng |
| A8 | Hoàn tác / Làm lại | Ctrl+Z / Ctrl+Y cho mọi thao tác sửa |
| A9 | Cắt / Chép / Dán | Ctrl+X/C/V, dán giữ định dạng và dán chỉ chữ; dán từ Word/Excel ngoài vào |
| A10 | Tìm / Thay thế | Ctrl+F / Ctrl+H |
| A11 | Thu phóng | Thanh trượt + Ctrl+lăn chuột |
| A12 | Giao diện | 100% tiếng Việt; ribbon các tab chuẩn; thanh trạng thái; phím Alt hiện phím tắt ribbon |
| A13 | Trợ giúp | F1 mở Trợ giúp tiếng Việt đúng tính năng |
| A14 | Tự lưu / khôi phục | Có (đã xong) |

## B. VN Writer (Gói G1)
| # | Mục | Chuẩn Word |
|---|---|---|
| B1 | Gõ tiếng Việt | Unikey/Telex/VNI, Unicode dựng sẵn, không mất dấu, không nhảy con trỏ |
| B2 | Định dạng ký tự | Phông, cỡ (cả 13,5), đậm/nghiêng/gạch chân, màu chữ, tô nền, chỉ số trên/dưới, Ctrl+B/I/U, Ctrl+Shift+>/< |
| B3 | Định dạng đoạn | Căn trái/giữa/phải/đều (Ctrl+L/E/R/J), thụt lề, thụt dòng đầu, giãn dòng 1/1,15/1,5/2/chính xác, khoảng cách trước/sau |
| B4 | Danh sách | Gạch đầu dòng, đánh số 1. a) i., nhiều cấp, Tab/Shift+Tab đổi cấp, tiếp tục/bắt đầu lại đánh số |
| B5 | Kiểu | Normal, Heading 1–3, Title; mục lục tự động từ Heading |
| B6 | Bảng | Chèn bảng, thêm/xóa hàng cột, gộp/tách ô, viền, độ rộng cột, lặp tiêu đề bảng |
| B7 | Trang | Khổ A4/Letter, lề, hướng dọc/ngang, ngắt trang Ctrl+Enter, ngắt section |
| B8 | Đầu/chân trang | Header/footer, số trang, trang đầu khác |
| B9 | Chèn | Ảnh (kéo thả, đổi cỡ, bao chữ), hình, hộp văn bản, ký hiệu, liên kết |
| B10 | Thước và chế độ xem | Thước ngang/dọc, Print Layout, số trang/số từ ở thanh trạng thái |
| B11 | Kiểm tra chính tả tiếng Việt | Gạch đỏ, gợi ý |
| B12 | Theo dõi thay đổi, chú thích | Track changes, comment (hiển thị và lưu đúng) |

## C. VN Sheet (Gói G2)
| # | Mục | Chuẩn Excel |
|---|---|---|
| C1 | Nhập liệu | Số, ngày (dd/mm/yyyy), giờ, %, tiền VND; tự nhận kiểu; Enter/Tab/mũi tên di chuyển; F2 sửa ô; Alt+Enter xuống dòng trong ô |
| C2 | Công thức | Thanh công thức, tham chiếu tương đối/tuyệt đối (F4), 30 hàm thông dụng (SUM, AVERAGE, IF, VLOOKUP, COUNTIF, SUMIF, ROUND, TEXT, DATE, TODAY, IFERROR, INDEX, MATCH, CONCAT, LEFT/RIGHT/MID...), lỗi #DIV/0!, #N/A hiển thị đúng |
| C3 | Chọn | Ô, vùng, cả hàng/cột, Ctrl+A, Shift+mũi tên, Ctrl+mũi tên |
| C4 | Kéo điền | Chuỗi số, ngày, thứ, tháng, công thức; nhấp đúp tay điền |
| C5 | Hàng / cột | Chèn/xóa (công thức tự điều chỉnh), đổi độ rộng/cao, tự khớp, ẩn/hiện |
| C6 | Định dạng ô | Định dạng số (phân cách nghìn, thập phân, ngày, VND, %), căn lề, xuống dòng, gộp và căn giữa, viền, tô màu, phông |
| C7 | Trang tính | Thêm/xóa/đổi tên/di chuyển/sao chép trang, màu tab |
| C8 | Dữ liệu | Sắp xếp, lọc (AutoFilter), cố định hàng/cột, xác thực dữ liệu, loại trùng |
| C9 | Định dạng có điều kiện | Tô màu theo giá trị cơ bản |
| C10 | Biểu đồ | Cột, đường, tròn từ vùng chọn; lưu ra xlsx giữ biểu đồ |
| C11 | In | Vùng in, vừa 1 trang, lặp tiêu đề hàng, đầu/chân trang, ngắt trang |
| C12 | Tính toán | Tự tính lại; file lớn không treo |

## D. VN Slides (Gói G8)
| # | Mục | Chuẩn PowerPoint |
|---|---|---|
| D1 | Trang chiếu | Thêm (Ctrl+M), xóa, nhân bản, kéo sắp xếp ở khung trái, bố cục (Tiêu đề, Tiêu đề + nội dung, Trống...) |
| D2 | Chỗ giữ chỗ | Chữ gợi ý mờ "Bấm để thêm tiêu đề" (không phải nội dung thật) |
| D3 | Văn bản | Hộp văn bản, phông/cỡ/màu, gạch đầu dòng, căn lề |
| D4 | Đối tượng | Chèn ảnh, hình, bảng; di chuyển, đổi cỡ, xoay, căn chỉnh, sắp lớp |
| D5 | Thiết kế | Chủ đề/màu nền cơ bản, cỡ trang 16:9 / 4:3 |
| D6 | Trình chiếu | F5 từ đầu, Shift+F5 từ trang hiện tại, mũi tên/Esc, hiệu ứng chuyển trang cơ bản |
| D7 | Ghi chú | Ghi chú người thuyết trình, lưu đúng |
| D8 | Lưu / xuất | pptx, ppt, pdf; PowerPoint mở lại đúng |

## Cách rà soát
Mỗi gói: kiểm từng mục theo bảng trên → ghi ĐẠT / CHƯA ĐẠT + mô tả ngắn → sửa mục CHƯA ĐẠT → Claude kiểm lại đúng các mục đó một lần.
Lỗi chi tiết ngoài danh mục: ghi vào danh sách lỗi, sửa dần theo mức độ ảnh hưởng.
